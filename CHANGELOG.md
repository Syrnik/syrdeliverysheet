# Changelog

## [Unreleased]
### Fixed
 - Добавлен шаблон печатной формы для интерфейса UI 2.0 (`templates/actions/printform/PrintformDisplay.html`) со скриптом инлайн-редактирования полей перед печатью — раньше эта возможность была доступна только в устаревшем интерфейсе (`templates/actions-legacy`)

### Changed
 - Добавлены GitHub Actions: проверка совместимости с PHP и автоматический релиз по тегу `vX.Y.Z`
 - Обновлён README: исправлены опечатки и уточнены формулировки
 - `.editorconfig` добавлен в список исключений сборки (`lib/config/exclude.php`)

### Removed
 - Список контрибьюторов (`contributors.txt`) и конфиг Rector — заменены файлами лицензии (`LICENSE`, `LICENSE_ru`) и скриптом сборки архива (`compress-app-plugin.php`)

## [2.0.1] - 2023-05-20
### Fixed
 - Отображение номера телефона получателя приведено в соответствие с фреймворком Webasyst 2.8+
 - Рефакторинг, удалён мёртвый код

## [2.0.0] - 2022-12-06
### Added
 - Поддержка Shop-Script Premium
 - Вывод желаемой или согласованной даты доставки заказа (#31.1)
 - Поддержка единиц измерения и дробных количеств товаров (#31.1)
 - Файл требований плагина (`lib/config/requirements.php`): PHP >=7.4, Shop-Script >=7.2, Installer >=2.0

### Fixed
 - Исправлен вывод списка товаров в печатной форме (#31.1)
 - В данные товара добавлено поле `sku_id` (Resolves #1)
 - `$items` используется вместо `$order->items` для ясности кода; исправлена опечатка (#1)

### Changed
 - Плагин переработан под современные требования Webasyst
 - Скриншоты и логотип исключены из архива релиза
